# Marketing Skills

Skills, instructions, and templates for your coding agent to do marketing.

Hand this page to the agent that writes code for you. It reads the instructions, adapts the template into your project, and you review the result.

## What's included

Open the name for a short overview. Open Instructions for the steps your agent follows.

## How to use them

1. Open your coding agent.
2. Share this page, or the row you want.
3. Say what you want in normal language:
   - "Set up SEO so we draft and publish articles to the blog."
   - "Set up Google Ads so it reviews the account every day."
   - "Set up cold email in Instantly and draft the replies for me."
4. Your agent follows the instructions and adapts the template. You review what it built.
